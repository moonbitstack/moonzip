01 — Deflate & gzipThe smallest unit is a buffer.

deflate is the raw codec (RFC 1951). gzip wraps it with a ten-byte header, a CRC-32 and a length (RFC 1952). zlib wraps it with a two-byte header and an Adler-32 (RFC 1950). All three round-trip to the byte.

compress & read back
moonbit
fn main raise {
  let out : Array[Byte] = []
  for _ in 0..<200 {
    for b in "the quick brown fox jumps over the lazy dog. " {
      out.push((b.to_int() % 256).to_byte())
    }
  }
  let body = Bytes::from_array(out)
  println("original  -> \{body.length()} bytes")

  let raw = @deflate.deflate(body[:])
  println("deflate   -> \{raw.length()} bytes, back to \{@deflate.inflate(raw[:]).length()}")

  let gz = @gzip.gzip(body[:])
  println("gzip      -> \{gz.length()} bytes, back to \{@gzip.gunzip(gz[:]).length()}")

  let zl = @zlib.zlib(body[:])
  println("zlib      -> \{zl.length()} bytes, back to \{@zlib.unzlib(zl[:]).length()}")
}
output
original  -> 9000 bytes
deflate   -> 87 bytes, back to 9000
gzip      -> 105 bytes, back to 9000
zlib      -> 93 bytes, back to 9000
a tampered stream

A container that carries a checksum checks it. Flip one byte of the trailing CRC and gunzip refuses, rather than hand back bytes that look right and are not.

moonbit
fn main raise {
  let out : Array[Byte] = []
  for _ in 0..<200 {
    for b in "the quick brown fox jumps over the lazy dog. " {
      out.push((b.to_int() % 256).to_byte())
    }
  }
  let body = Bytes::from_array(out)

  let gz = @gzip.gzip(body[:])
  let bent = gz.to_array()
  bent[gz.length() - 8] = (bent[gz.length() - 8].to_int() ^ 0xFF).to_byte()
  try @gzip.gunzip(Bytes::from_array(bent)[:]) |> ignore catch {
    Checksum(..) => println("tampered  -> refused: the checksum does not match")
    _ => println("tampered  -> refused")
  } noraise {
    _ => println("tampered  -> accepted, which would be the bug")
  }
}
output
tampered  -> refused: the checksum does not match

The same input gives the same bytes every time: gzip writes a zero modification time by default, so a build stays reproducible.

02 — Archivesgzip holds one thing; zip and tar hold many.

zip is random-access: a central directory at the end names every member, so listing reads that and stops. tar is one header per file and no compressed members; targz is a tarball through gzip, which is all a .tar.gz ever was.

build & read
moonbit
fn main raise {
  let entries = [
    @zip.Entry::new("readme.txt", b"a member of an archive\n", mtime=1700000000L),
    @zip.Entry::new("data/table.csv", b"name,size\nreadme,24\n"),
  ]
  let archive = @zip.zip(entries[:])
  println("zip       -> \{archive.length()} bytes, \{@zip.names(archive[:]).length()} members")
  println("zip names -> \{@zip.names(archive[:]).join(", ")}")
  let back = @zip.unzip(archive[:])
  println("unzip     -> \{back.length()} members, first is \{back[0].name}")

  let files = [
    @tar.Entry::new("readme.txt", b"a member of an archive\n", mtime=1700000000L),
    @tar.Entry::new("data/table.csv", b"name,size\nreadme,24\n"),
  ]
  let tarball = @tar.tar(files[:])
  let gzipped = @tar.targz(files[:])
  println("tar       -> \{tarball.length()} bytes")
  println("tar.gz    -> \{gzipped.length()} bytes")
}
output
zip       -> 265 bytes, 2 members
zip names -> readme.txt, data/table.csv
unzip     -> 2 members, first is readme.txt
tar       -> 3072 bytes
tar.gz    -> 170 bytes

Listing reads only the directory; unzip expands on demand, so a caller can pull one member without touching the rest.

03 — StreamingThe body never has to be in one piece.

A response body arrives in chunks; a file is read four kilobytes at a time. The Writer/Reader pair takes it a piece at a time and never holds the whole thing — only the 32 KiB window a back-reference can reach, plus four bytes of running checksum. push returns what is ready; finish flushes the rest and checks the trailer.

4 KiB out, 777 B in
moonbit
fn main raise {
  let out : Array[Byte] = []
  for i in 0..<4000 {
    for b in "the quick brown fox jumps over the lazy dog. " {
      out.push((b.to_int() % 256).to_byte())
    }
    out.push((i % 251).to_byte())
  }
  let source = Bytes::from_array(out)
  println("body      -> \{source.length()} bytes")

  let writer = @gzip.Writer::new(level=9)
  let packed : Array[Byte] = []
  let mut at = 0
  while at < source.length() {
    let stop = if source.length() - at < 4096 { source.length() } else { at + 4096 }
    for b in writer.push(source[at:stop]) { packed.push(b) }
    at = stop
  }
  for b in writer.finish() { packed.push(b) }
  let gzipped = Bytes::from_array(packed)
  println("gzip      -> \{gzipped.length()} bytes (\{100 - gzipped.length() * 100 / source.length()}% smaller)")

  let reader = @gzip.Reader::new()
  let got : Array[Byte] = []
  let mut at2 = 0
  while at2 < gzipped.length() {
    let stop = if gzipped.length() - at2 < 777 { gzipped.length() } else { at2 + 777 }
    for b in reader.push(gzipped[at2:stop]) { got.push(b) }
    at2 = stop
  }
  for b in reader.finish() { got.push(b) }
  println("gunzip    -> \{Bytes::from_array(got).length()} bytes, matches: \{Bytes::from_array(got) == source}")
}
output
body      -> 184000 bytes
gzip      -> 1983 bytes (99% smaller)
gunzip    -> 184000 bytes, matches: true

The home page runs the same algorithm in the browser; here it is in MoonBit, on a body fed back in pieces that fall inside headers and codes.

04 — Choosing a formatNo format wins.

The numbers are one 184,000-byte body of English text with a periodic tail, printed by src/examples/stream and src/examples/formats. They are the same body the home page's strata show — here as a table, with what each format is for.

Pick by what the caller does with the bytes. Servicing a request: lz4 or snappy. Storing a file people download: gzip or zstd. Shipping a tarball: gzip for speed, xz for size. Every function above is documented in the API reference.
